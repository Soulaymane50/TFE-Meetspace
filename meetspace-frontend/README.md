# MeetSpace Frontend

Application React/Vite de MeetSpace.

## Prerequis

- Node.js 20 ou plus
- backend MeetSpace accessible sur l'URL configuree dans `VITE_API_URL`

## Installation

```bat
npm install
```

## Lancement

```bat
npm run dev -- --port 5174
```

## Verification

```bat
npm run lint
npm run build
```
